# understand lasertag

Lasertag is zero-runtime structural CSS for JSX with CSS Modules. This page is a
stub for the guide that will explain the model, conventions, and analysis tools.

More formally, Lasertag is a **statically enforced subset of CSS Modules**.
Every Lasertag stylesheet is an ordinary CSS Module with additional structural
constraints checked by tooling. Anything that supports CSS Modules can, by
definition, support Lasertag—without adopting a new styling runtime, module
format, or bundler contract.

## structural CSS

Components and styles describe the same tree. Lasertag compares those structures
without adding a runtime to the application.
