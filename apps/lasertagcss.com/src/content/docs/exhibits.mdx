## how exhibits work

The `<Exhibit>` component reads source from `src/exhibits`, derives syntax
highlighting from the displayed filename, and renders it with the same copyable
code block used across the site. Files ending in `.txt` display without that
suffix, allowing intentionally invalid or framework-specific examples to remain
documentation fixtures rather than compiled site code.

Named regions can show one focused part of a larger source file:

<Exhibit
  src="getting-started/AppHeaderBar.tsx#component"
  label="component region"
  soft
/>

Region markers are stripped from the rendered result. Prefer full files when
the surrounding context teaches something; use a region when the complete file
would bury the idea being explained.
